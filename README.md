# Precision Forge

Quero criar uma NOVA HOME PAGE para a UNISOLDAS SOLUÇÕES com aparência de site industrial premium, moderno e de alto padrão.

Site atual como referência:

https://www.unisoldasolucoes.com.br

IMPORTANTE:

Não quero um layout genérico de empresa.

Quero uma experiência visual que pareça ter sido desenvolvida por uma agência especializada em grandes empresas industriais.

A primeira impressão precisa transmitir:

- força

- precisão

- tecnologia

- engenharia

- confiança

- qualidade

- profissionalismo

- capacidade técnica

O visitante precisa entrar no site e imediatamente perceber que está diante de uma empresa séria e profissional.
